# Рекомендательная система мест Москвы

Учебный проект по рекомендательным системам. Идея простая: собрать места Москвы (кафе, парки, музеи и т.д.), добавить к ним признаки типа уютное, для семьи, дёшево - и попробовать искать по запросам вроде куда пойти с ребёнком бесплатно.

## Как это устроено

Всё в одном ноутбуке `pipeline.ipynb`. Пять заданий, идут по порядку.

**Сбор данных** - пробовал KudaGo, он вернул 403. Перешёл на Wikidata SPARQL: бесплатно, без ключей, есть русские названия и координаты. Получилось около 60 мест по пяти категориям: рестораны, кафе, музеи, кинотеатры, парки.

**Семантические признаки** - чтобы отвечать на вопросы с кем идти, за сколько, какая атмосфера. Придумал пять признаков: `тип_опыта`, `атмосфера`, `контекст`, `бюджет`, `время_дня`.

**Извлечение признаков** - rule-based по ключевым словам в описании. Если в тексте есть детск или аттракцион - атмосфера семейное. Если текста нет (а его нет у большинства) - ставим дефолт по категории. Честно: примерно 80% признаков из дефолта, не из текста. Wikidata не очень щедрая на описания.

**EDA** - шесть графиков: по категориям, атмосфере, бюджету, тепловая карта, полнота описаний, карта координат. Основной вывод - данных мало, описания скудные, но пайплайн рабочий.

**Поиск** - TF-IDF с символьными n-граммами + cosine similarity. Опционально sentence-transformers, если хочется семантики. Каждое место превращается в строку из всех своих признаков, запрос ищется в этом пространстве.

## Структура проекта

* `pipeline.ipynb` - основной ноутбук с кодом (сбор данных, разметка, поиск и визуал).
* `README.md` - описание решения.
* `data/` - папка с данными:
  * `places_moscow.csv` - сырой датасет из Wikidata.
  * `places_enriched.csv` - данные после добавления семантических признаков.
  * `search_results.csv` - результаты работы поиска на тестовых запросах.
  * `plot_*.png` - сохраненные графики.

## Запуск

Открыть `pipeline.ipynb` в Google Colab, запустить всё подряд (`Runtime - Run all`).

В первый раз ноутбук сходит в Wikidata и сохранит данные в `data/`. При повторном запуске просто загрузит CSV - быстро.

Зависимости ставятся в первой ячейке:

```
pip install sentence-transformers scikit-learn pandas matplotlib seaborn
```

## Что не получилось и почему

- **Мало текста.** Wikidata для большинства мест даёт одно предложение типа кафе в Москве, Россия. Нормальный NLP на таком не построишь.
- **Признаки грубые.** Почти всё - дефолт по категории. Было бы круто разметить через LLM, но нет бесплатного API.
- **TF-IDF тупит на нечётких запросах.** Тихое место для чтения - он не понимает, что это. Нужны эмбеддинги, а в идеале - нормальные отзывы в данных.
